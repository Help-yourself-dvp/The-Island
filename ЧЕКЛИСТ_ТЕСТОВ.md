## Browser preview / функциональный тест

- [ ] Loading screen исчезает; ошибок загрузки нет.
- [ ] Player не проваливается сквозь землю и имеет правильный масштаб (1.78).
- [ ] **Коллизии:** игрок НЕ проходит сквозь деревья, камни, здание мастерской, склад и заборы.
- [ ] **Граница острова:** `clampToLand` удерживает игрока в пределах суши.
- [ ] Idle включается без движения; при движении включается Walk или Run без скольжения ног.
- [ ] При беге прямо в стену/препятствие (скорость < 0.25) шаги не стучат как при свободном беге.
- [ ] Первый touch/key запускает мягкое море и легкий ветер (без низкочастотного гула 92 Гц).
- [ ] Птицы звучат редкими случайными трелями (интервалы 8–35 секунд) с естественными паузами.
- [ ] При ходьбе/беге шаги различаются по темпу и громкости (Walk мягче и реже, Run быстрее и отчетливее).
- [ ] При переходе между тропой (dirt), поляной (grass), платформой мастерской (wood) и берегом (stone) меняется акустика шагов.
- [ ] Camera button переключает ракурсы.
- [ ] `#shot-zone1-start`, `#shot-zone1-forest`, `#shot-zone1-sawmill`, `#shot-zone1-future-path`, `#shot-zone1-overview` корректно работают и показывают разные участки единой зоны.
- [ ] Параметр `?colliders=1` отображает 3D-сетки коллидеров.
