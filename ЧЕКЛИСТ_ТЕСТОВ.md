# Чеклист тестов — Stage 0

## Перед push

- [ ] `npm ci` проходит на чистом checkout.
- [ ] `npm run assets:audit` подтверждает только GLB в production.
- [ ] `npm run build` проходит.
- [ ] `npm run test:soak` проходит минимум 120 виртуальных секунд.
- [ ] В bundle нет CDN/remote asset URL.
- [ ] `version.txt`, package.json и Android versionName совпадают.
- [ ] Git diff не содержит случайных source-pack copies, cache или secrets кроме документированного alpha keystore.

## Browser preview

- [ ] Loading screen исчезает; ошибок загрузки нет.
- [ ] Player не проваливается и имеет правильный масштаб.
- [ ] Idle включается без движения; walk включается в движении; нет sliding.
- [ ] WASD/стрелки соответствуют экранному направлению.
- [ ] Стик возвращается в центр после отпускания/cancel.
- [ ] Camera button переключает два ракурса.
- [ ] Камера не уходит под terrain и не теряет player.
- [ ] `#shot-art`, `#shot-player`, `#shot-building` воспроизводимы.
- [ ] `?quality=medium&debug` показывает компактную диагностику.
- [ ] После background/resume нет второго loop и резкого скачка.
- [ ] 60–120 секунд: нет исключений и монотонного роста diagnostics counters.

## GitHub Actions / APK

- [ ] Job `apk` завершён успешно.
- [ ] Artifact называется `island-revival-0.1.1-art-audition`.
- [ ] В архиве есть `island-revival-0.1.1-art-audition.apk`.
- [ ] Workflow подтвердил отсутствие `android.permission.INTERNET`.
- [ ] APK подписан alpha-сертификатом; следующая версия устанавливается поверх предыдущей.

## Honor Magic 8 Pro — обязательный device review

- [ ] Установка и первый запуск проходят без сети.
- [ ] Landscape и fullscreen корректны; UI не попадает под cutout/system bars.
- [ ] Экран не гаснет во время игры.
- [ ] Сцена остаётся рабочей через 30, 60 и 120 секунд.
- [ ] FPS/плавность приемлемы на HIGH; записать фактическое наблюдение, не переносить desktop FPS.
- [ ] Проверить MEDIUM отдельно.
- [ ] Touch movement не инвертировано и не «липнет».
- [ ] Camera удобна; player не теряется за trees/building.
- [ ] Нет z-fighting, чёрных foliage, clipping и floating props.
- [ ] Оценить player, trees, rocks/plants, building, lighting и world scale.
- [ ] Ответить, выглядит ли сцена как production foundation, а не дешёвый prototype.

## Stop gate

Даже после успешного чеклиста не начинать Stage 1 без явной команды: **«STAGE 0 ПРИНИМАЮ. ПЕРЕХОДИ К STAGE 1»**.
